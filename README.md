# Arrière-plans d'Aurora Player

Photos d'aurores boréales affichées sur l'accueil d'Aurora Player (mode « Aurores boréales », réglage par défaut).
L'appli en contient 3 et télécharge les autres d'ici.

- `tv/NN.jpg` : version paysage (1920×1072) — Android TV, Samsung, LG, VIDAA, tablettes en paysage
- `phone/NN.jpg` : version portrait (1072×1920) — téléphones
- `photos.json` : liste des photos ; `name` est le lieu affiché au-dessus de la barre de l'accueil

Ajouter une photo : mettre `NN.jpg` dans `tv/` et `phone/`, puis une ligne dans `photos.json` (numéro suivant).
Les applis voient la nouvelle liste au plus tard le lendemain.
